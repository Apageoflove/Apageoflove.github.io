UniDrive

A personal cloud-storage utility.

UniDrive is a personal tool that lets its owner access their own cloud drives (Google Drive, MEGA, OneDrive, Dropbox, pCloud, Koofr, Filen) through a single mounted drive letter on Windows.

It is used exclusively by its owner for personal file storage and file management. The application does not offer any public service, does not collect any user data, and does not share any information with third parties.

Google user data accessed by this application is used only to read and write files in the owner's own Google Drive account, at the owner's direct request.
